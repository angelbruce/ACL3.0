# 工作区项目自动发布 Docker 容器流程

## 一、系统架构概览

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              用户请求层                                      │
│                                                                             │
│  POST /api/project-container-configs/:project_id/start                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                            workspace-svc 服务                               │
│                                                                             │
│  ┌─────────────┐    ┌─────────────────┐    ┌─────────────────────────┐    │
│  │  handlers   │───▶│ ContainerDeployer│───▶│  llm-svc (LLM 调用)    │    │
│  │  (HTTP处理)  │    │   (容器部署逻辑)  │    │                         │    │
│  └─────────────┘    └─────────────────┘    └─────────────────────────┘    │
│         │                   │                        │                      │
│         │                   ▼                        ▼                      │
│         │          ┌─────────────────┐      ┌─────────────────────┐        │
│         │          │   Docker Host   │◀────▶│   MCP-SSE 服务      │        │
│         │          │                 │      │   (容器内运行)      │        │
│         │          └─────────────────┘      └─────────────────────┘        │
│         │                                                          │        │
│         │          ┌─────────────────────────────────────────────┘        │
│         │          │                                                        │
│         ▼          ▼                                                        │
│  ┌─────────────┐                                                          │
│  │  Database   │  project_files, project_container_configs                 │
│  └─────────────┘                                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 二、部署流程详细说明

### 阶段一：用户发起部署请求

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  阶段一：用户发起部署请求                                                     │
└─────────────────────────────────────────────────────────────────────────────┘

用户操作：
  POST /api/project-container-configs/:project_id/start
  Headers: Authorization: Bearer <token>

                    │
                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  handlers.rs: start_container()                                            │
│                                                                             │
│  1. 从 JWT Token 提取 user_id                                               │
│  2. 从 Path 提取 project_id                                                 │
│  3. 验证用户权限                                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 三、LLM 部署任务详解

│  Model ID: 101                                                             │

│  【MCP 服务说明】                                                            │
│                                                                             │
│  每个容器启动后，内部端口 80 会映射到宿主机的随机端口                          │
│  容器内置了 MCP-SSE 服务，支持以下工具：                                     │
│                                                                             │
│  - execute_command: 在容器内执行命令                                         │
│  - file_reader: 读取文件内容                                                │
│  - file_writer: 写入文件内容                                                │
│  - environment_check: 检测代码环境                                          │
│  - build_check: 检测编译结果                                               │
│  - process_monitor: 监控进程状态                                            │
│  - port_check: 检查端口监听状态                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### LLM 执行的具体步骤

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  步骤 1: 分析文件归属                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

LLM 分析每个文件应该属于哪个容器：

┌─────────────────────────────────────────────────────────────────────────────┐
│  分析结果示例：                                                              │
│                                                                             │
│  api-server 容器：                                                          │
│    - src/api/main.py (Flask 应用入口)                                       │
│    - requirements.txt (Python 依赖)                                         │
│    - config.py (配置文件)                                                   │
│                                                                             │
│  worker 容器：                                                              │
│    - src/worker/tasks.py (Celery 任务)                                      │
│    - requirements.txt (Python 依赖)                                         │
│                                                                             │
│  frontend 容器：                                                            │
│    - src/frontend/* (React 前端代码)                                        │
│    - package.json (Node.js 依赖)                                           │
│                                                                             │
│  共享文件：                                                                 │
│    - docker-compose.yml (项目配置)                                          │
│    - .env (环境变量文件)                                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  步骤 2: 分配文件到卷目录                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

LLM 使用 execute_command 工具将文件写入对应容器目录：

┌─────────────────────────────────────────────────────────────────────────────┐
│  api-server:                                                                │
│    - /debug/123/456/volumes/api-server/                                     │
│      ├── src/api/main.py                                                   │
│      ├── requirements.txt                                                  │
│      └── config.py                                                         │
│                                                                             │
│  worker:                                                                    │
│    - /debug/123/456/volumes/worker/                                        │
│      ├── src/worker/tasks.py                                               │
│      └── requirements.txt                                                  │
│                                                                             │
│  frontend:                                                                  │
│    - /debug/123/456/volumes/frontend/                                      │
│      ├── src/frontend/*                                                    │
│      └── package.json                                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  步骤 3: 获取端口映射                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

LLM 获取容器端口映射信息：

┌─────────────────────────────────────────────────────────────────────────────┐

## 七、注意事项

1. **端口映射**：容器内部端口 80（MCP-SSE）会自动映射到宿主机随机端口
2. **文件归属**：LLM 智能分析文件内容，决定文件归属哪个容器
3. **卷映射**：每个容器有独立的卷目录，docker-compose 自动管理
4. **MCP 工具**：容器启动后，需要 LLM 注册并使用 MCP 工具进行环境检测和依赖安装
5. **异步执行**：容器启动和 LLM 调用是异步执行的，返回结果仅表示启动请求成功
6. **安全考虑**：目前不考虑越权问题，需要后续补充权限验证
